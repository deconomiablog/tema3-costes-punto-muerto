# Tema 3 · Costes de producción y umbral de rentabilidad

Aplicación web para **Economía de 1.º de Bachillerato**.

## Qué permite practicar

- Costes fijos y variables.
- Coste total.
- Costes medios.
- Coste marginal.
- Ingresos, costes y beneficio.
- Umbral de rentabilidad o punto muerto.
- Margen de contribución.
- Interpretación de cambios en precio, costes fijos y coste variable unitario.
- Lectura de tablas y gráficas.

## Funcionamiento

La aplicación ofrece tres bloques:

1. **Costes de producción**
2. **Umbral de rentabilidad**
3. **Prueba mixta**

Cada bloque dispone de un banco de **40 preguntas**. En cada intento se muestran **10 preguntas aleatorias**.

Hay tres niveles:

- Básico
- Aplicación
- Reto

La corrección es inmediata. En preguntas con más de dos opciones existe un segundo intento. El botón de ayuda resta **0,25 puntos** en esa pregunta.

Al finalizar se muestra:

- puntuación;
- número de ayudas utilizadas;
- resultado por contenidos;
- diagnóstico orientativo sobre qué conviene repasar.

Varias preguntas generan datos numéricos distintos en cada intento.

## Archivos

- `index.html`: estructura de la web.
- `styles.css`: diseño.
- `question-helpers.js`: funciones comunes del banco de preguntas.
- `costs.js`: banco de 40 preguntas de costes.
- `point.js`: banco de 40 preguntas de punto muerto.
- `app.js`: funcionamiento del cuestionario.
